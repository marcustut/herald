Open source · self-hosted

Your coding agents email you when they finish.

Agents run in terminals, in CI, and on other machines — and you end up checking each one to see if it's done. Herald gathers those updates and emails you when a task finishes, fails, or gets stuck. One gateway for every project, and no dashboards to babysit.

Recipients are pinned server-side from the token — agents set no headers and cannot redirect mail.

Who it's for

01

Developers running many agents

One gateway for every project. A per-project token points at a fixed recipient, so a stray prompt can't mail someone else.

02

Small teams and self-hosters

PostgreSQL is the queue, the audit log, and the credential store. Deploy it with Docker or NixOS; SMTP or a webhook sink is enough.

03

CI and long-running jobs

Notify on the terminal state only — success, failure, or blocked — not every step. At-least-once delivery with backoff and a dead state.

Self-host now

No account and no build step. Clone, start Compose, create a token, and send your first event in under ten minutes.

How an agent sends it

Install the skill so an agent notifies you only when you ask, then send from the CLI or straight over HTTP.

The gateway is independent of the harness: the CLI, MCP (send_event), or a lifecycle hook all hit POST /v1/events.
